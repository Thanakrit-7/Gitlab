# ตารางตรวจ Lab 03 — A1–A5

เว็บ: http://127.0.0.1:5000/ (Flask)
วิธีตรวจจริง: **OpenCode Browser** (in-app browser ของ OpenCode) — เปิดหน้าเว็บจริง เลือกโหมด กรอกค่าผ่านฟอร์ม กดปุ่มคำนวณ และอ่านผลจากหน้าเว็บ
เกณฑ์ยอมรับ: |ΔIC| ≤ 0.01 mA และ |ΔVCE| ≤ 0.02 V เทียบค่าคาดหมายที่ไม่ปัดเศษ
เงื่อนไขร่วมทุกกรณี: `VCC = 12 V`, `RC = 2.2 kΩ`, `β = 100`, `VBE = 0.70 V`

ค่าคาดหมายคำนวณด้วยเครื่องคิดเลขจากสมการ Engineering Electronics (อิสระจากตัวโปรแกรม):

- Fixed: `IB = (VCC − VBE) / RB`, `IC = β·IB`, `VE = 0`, `VC = VCC − IC·RC`, `VCE = VC − VE`
- Emitter: `IB = (VCC − VBE) / (RB + (β+1)·RE)`, `IE = (β+1)·IB`, `VE = IE·RE`, `VB = VE + VBE`, `VC = VCC − IC·RC`, `VCE = VC − VE`
- Divider: `VTH = VCC·R2/(R1+R2)`, `RTH = R1·R2/(R1+R2)`, `IB = (VTH − VBE)/(RTH + (β+1)·RE)`

## หมายเหตุ

- กรณียังไม่มีโหมดไม่รู้จัก (`mode=foo`): Flask คืน 400 พร้อมข้อความ "ไม่รู้จักโหมด ..." (ตรวจผ่าน test client — ไม่เดาเป็น Divider)
- ผลของ Divider ไม่เปลี่ยนจาก Lab 2 (61/61 tests ยังผ่าน)
- การสลับโหมดผ่าน dropdown + ปุ่ม "โหลดฟอร์ม" ทำให้ server re-render ฟอร์มของโหมดนั้น (ไม่มี JavaScript); ค่าที่พิมพ์ในโหมดอื่นไม่ถูกเก็บข้ามการ reload
