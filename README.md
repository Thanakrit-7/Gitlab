คำอธิบาย: โปรแกรมประมวลผลคำนวณค่าทางไฟฟ้าสำหรับวงจรไฟฟ้ากระแสตรง (DC) ทั้งแบบอนุกรม ขนาน และผสม โดยระบุค่าแรงดันและตัวต้านทานผ่านอินเทอร์เฟซที่ใช้งานง่าย

วัตถุประสงค์: เพื่อคำนวณค่ากระแสไฟฟ้ารวม กระแสย่อย และกำลังไฟฟ้าที่เกิดขึ้นในแต่ละตัวต้านทานได้อย่างแม่นยำ ช่วยลดความซับซ้อนและลดความผิดพลาดในการคิดคำนวณด้วยมือ
